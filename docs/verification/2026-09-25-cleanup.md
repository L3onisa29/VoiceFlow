# Desktop repository cleanup, 2026-09-25

Baseline: `1e084b7`, branch `codex/tauri-streaming-app`, clean working tree.
The requested scope was to retain only the new desktop version in this project.

## Removed

- The old Python implementation and its tests, including the T3 bridge and
  postprocessing integrations: 104 Python source files in total.
- Python dependency manifests, lockfile, version pin, type-check configuration,
  application YAML configuration and the postprocessing schema.
- Python benchmark fixtures/scripts, LaunchAgent template/installer and obsolete
  reproduction instructions.
- The local `.venv`, Python test/lint caches, coverage data and old wheel/source
  distributions. The virtual environment alone occupied approximately 238 MB.

The old implementation remains available in Git history. No current desktop
source, model manifest, model files, signing configuration or app preferences
were removed. The old LaunchAgent was not installed at its documented location,
and no process using this project's Python environment was running.

## Updated

README and desktop documentation now describe the Rust/Tauri application only.
The desktop documentation moved from `docs/desktop-migration.md` to
`docs/desktop.md`; links were updated. Existing desktop verification records
remain as dated evidence, including their unresolved T3 insertion limitation.

CI now checks Node/TypeScript and Rust on macOS. It builds the UI, tests the
signing policy, runs Rustfmt, Clippy and Rust tests, then compiles release
binaries. It does not publish an unsigned bundle. Signed packaging remains the
local `pnpm desktop:build` command.

## Verification

- `pnpm desktop:check` and `pnpm desktop:ui` passed.
- All 14 Rust tests and 3 signing-policy tests passed.
- Rustfmt, Clippy with warnings denied, changed-file formatting and diff checks
  passed.
- A separate read-only audit found no application-source changes and no Python
  code or distributions remaining outside dependency/build directories.
- All Markdown file links resolve and the CI YAML parses.
- `pnpm desktop:build` succeeded after removal of the Python environment. The
  resulting bundle contains only the native executable, Info.plist, icon and
  code signature. It links no Python runtime, passes strict signature validation
  and has the same designated requirement as the previously verified build.

The CI workflow has been checked locally; no push or remote CI run was requested.
